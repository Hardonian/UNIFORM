## Published example

The four matrices in Solan–Vieille Figure 2 were transcribed into all 15 mask payoffs.
The exact one-shot checker finds no pure instant equilibrium. Under the paper's
period-two symmetry `(x,0,z,0)`, `(0,x,0,z)`, active-player indifference yields

```
2*x*z^2 - 5*x*z + 3*x + z^2 - 2*z = 0
3*x^2*z + x^2 - 6*x*z - 2*x + 3*z = 0.
```

Elimination gives

```
27*z^4 - 121*z^3 + 179*z^2 - 96*z + 15 = 0
132*x = 27*z^4 - 526*z^3 + 941*z^2 - 87*z.
```

The relevant root is approximately `z=0.2654747088302300`,
`x=0.2539025418087003`. The checked-in rational approximation has exact same-period
regret below `1e-14`.

The follow-up implementation represents the selected root by its quartic and the open
rational isolating interval
`(26547470883022/10^14, 26547470883024/10^14)`. A Sturm sequence proves that the
interval contains exactly one root. The profile and every value/deviation are evaluated
in the rational polynomial quotient, with signs decided by gcd and interval refinement.
All eight player/start-phase regrets reduce exactly to zero. This is an exact
single-instance period-two certificate, still restricted to same-period deviations.

## Adversarial checks

- floating JSON and decimal strings are rejected;
- incomplete payoff tables and invalid stochastic rows are rejected;
- never-absorbing periodic profiles use the explicit continuation payoff;
- certificates check every starting phase, not just phase zero;
- continuous AP pieces reject simultaneous-quitter density;
- model parsing separates rational values from algebraic/unknown expressions;
- Rust candidates are independently reconstructed and rechecked in Python.

## Search run

The Rayon scanner used counter-based SplitMix64, seed 7, integer payoffs in `[-4,4]`,
and exactly 1,000,000 sample IDs. It found 148,994 games without a pure equilibrium in
the one-shot continuation-payoff game and retained three maximum-margin candidates.
This is only a screening property; it says nothing about stationary mixed, periodic,
or nonperiodic equilibria.

## Independent tools

Elan 4.2.4 installed the pinned Lean 4.35.0 toolchain. Mathlib's 9,031-file binary
cache was retrieved and `lake build` completed all 3,139 jobs. The build exposed a
missing nonnegativity premise in an initial lemma draft; the statement was corrected
and rebuilt without `sorry` or added axioms. The successful log is checked in.

Z3 Python binding 5.3.1 and cvc5 binding 1.4.2 both returned SAT on the rational
one-player QF_NRA fixture, and both models passed the independent Fraction checker.
On the unconstrained Solan–Vieille period-2 epsilon-zero encoding, both returned
UNKNOWN under the bounded local run (30-second configured limit; cvc5 completed after
approximately 46 seconds because its limit applies per command). This is recorded as
UNKNOWN, not evidence against the algebraic candidate.

Solver execution now emits query hashes, timestamps, backend/version stamps, normalized
statuses (including timeout), independent-check state, separate raw streams, and an
optional native proof file. A two-solver smoke campaign produced rational SAT models
that both passed exact independent re-evaluation. Native proofs are retained but are
not relabelled as independently checked proofs.

The grid engine now supports complete exact enumeration, explicit caps, and disjoint
shards. The essential APS implementation now accepts finite unions of rational convex
polytopes and performs exact hyperplane/orthant clipping, so represented segments and
higher-dimensional faces are no longer discarded.

## Open gaps

- No global theorem or counterexample has been proved.
- The missing game behind the supplied CSV prevents independent reproduction.
- The exact algebraic layer covers one selected real generator; general multivariate
  algebraic solver models are not yet independently certified.
- Rational polytopes are represented exactly, but curved, irrational, and general
  semialgebraic essential-APS sets are not.
- Native solver UNSAT proofs can be retained but do not yet have an independent checker.
- Command-line Z3/cvc5 remain absent; the tested integration falls back to their
  official Python bindings and stamps their versions.
